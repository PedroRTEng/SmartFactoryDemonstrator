# Visualization Layer

## Purpose

Provides operators, engineers and managers with real-time visibility of production.

This layer transforms industrial data into dashboards and KPIs.

## Technologies

- Grafana
- Node-RED Dashboard
- Plotly Dash
- Power BI

## Planned Dashboards

- OEE
- Production
- Downtime
- Alarm Monitoring
- Machine Status
- Energy Consumption
