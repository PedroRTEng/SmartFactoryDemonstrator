# PLC Layer

## Purpose

This folder contains the industrial control application that simulates the production process of the Smart Factory Demonstrator.

The PLC is responsible for:

- Machine control
- State management
- Production counters
- Alarms
- Device diagnostics
- Communication with higher-level systems

## Technologies

- Allen-Bradley Studio 5000
- ControlLogix / CompactLogix
- Ladder Logic
- Structured Text
- User Defined Data Types (UDTs)
- Add-On Instructions (AOIs)
